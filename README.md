## 🛠️ How to Install

This guide shows you how to install the extension in Google Chrome on Windows.

### Step 1: Download

1. Click the download button above.
2. The file will save to your computer (usually in your Downloads folder).
3. You should see a file named something like `linkedin-feed-blocker.zip`.

### Step 2: Extract the File

1. Locate the downloaded `.zip` file in your Downloads folder.
2. Right-click the file.
3. Select "Extract All..." from the menu.
4. Choose a location (like your Desktop) and click **Extract**.

### Step 3: Enable Developer Mode in Chrome

1. Open Google Chrome.
2. In the address bar, type: `chrome://extensions`
3. Press **Enter**.
4. At the top-right of the page, toggle **Developer mode** to ON (it will turn blue).

### Step 4: Load the Extension

1. Still on the `chrome://extensions` page, click **Load unpacked** button located top-left.
2. In the file window that opens, navigate to the folder where you extracted the files in Step 2.
3. Click inside that folder (don't click on any files inside it).
4. Click **Select Folder** (or **Select Folder** if the folder is highlighted).

### Step 5: Verify It Works

1. The extension named **linkedin-feed-blocker** should now appear in your extensions list with its icon.
2. Go to LinkedIn.com. Your homepage feed should be gone, but you can still click other tabs like Jobs, Messaging, or Profile.

## ❓ Frequently Asked Questions

**Q: Does this affect my LinkedIn profile?**
A: No. It only removes the feed. Your profile, messages, jobs, search, and notifications all stay.

**Q: Can I turn it on/off?**
A: Yes. Click the puzzle piece icon in Chrome's toolbar (top-right), find the extension, and toggle the switch.

**Q: Is it safe?**
A: Yes. It only interacts with LinkedIn's pages to hide the feed. It does not collect or send any data.

**Q: What if the feed still shows?**
A: Try refreshing the page or reloading the extension. If issues persist, reinstall following the steps above.

**Q: How do I completely remove it?**
A: Go to `chrome://extensions`, find "linkedin-feed-blocker", and click **Remove**.

## 🔄 Updating

This extension updates automatically when you reload Chrome. To manually update:

1. Go to `chrome://extensions`.
2. Toggle **Developer mode** ON.
3. Click the **Update** button in the top bar.
